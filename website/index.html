LOCAL SETUP 
Download the project ZIP using the source code link.
Extract it, then open a terminal in the project folder.
python -m pip install opencv-python numpy scipy imutils dlib Pillow
python drowsiness_detect.py

Windows is required for the current winsound alarm. dlib may require CMake and C++ build tools. Run from the repository folder so model and audio paths resolve.
